# 🛒 Online Retail Data Analysis using MySQL

## 📌 Project Overview

This project focuses on designing and analyzing an **Online Retail Database** using **MySQL**.

It demonstrates how relational database concepts and SQL queries can be used to manage and analyze retail business data.

The project includes data related to **customers, categories, products, orders, and order items**.

---

## 🎯 Project Objectives

The main objectives of this project are:

* Design a relational database for an online retail business.
* Create relationships between customers, products, categories, and orders.
* Store and manage retail data using MySQL.
* Perform SQL queries to analyze sales and customer behavior.
* Identify top customers and frequently ordered products.
* Analyze product categories and revenue.
* Visualize data using Power BI.

## 🔗 Database Relationships

```text
Customers
    │
    │ CustomerID
    ▼
Orders
    │
    │ OrderID
    ▼
OrderItems
    │
    ├──────────────► Products
    │                    │
    │                    │ CategoryID
    │                    ▼
    └──────────────► Categories
```

### Relationships

* One customer can place multiple orders.
* One order can contain multiple order items.
* One product can appear in multiple order items.
* One category can contain multiple products.

## 📊 SQL Analysis

The project contains **20 SQL queries** to analyze different aspects of online retail data.

### Analysis Performed

1. Retrieve all orders for a specific customer.
2. Calculate total sales for each product.
3. Calculate the average order value.
4. Identify the top customers based on total spending.
5. Find the most popular product category.
6. Insert a product with zero stock.
7. Find customers who placed orders in the last 30 days.
8. Calculate the total number of orders placed each month.
9. Retrieve details of the most recent order.
10. Calculate the average price of products in each category.
11. Identify customers who have never placed an order.
12. Calculate the total quantity sold for each product.
13. Calculate total revenue generated by each category.
14. Find the highest-priced product in each category.
15. Retrieve orders above a specified order value.
16. Count the number of orders containing each product.
17. Find the top 3 most frequently ordered products.
18. Calculate the total number of customers from each country.
19. Calculate total spending by each customer.
20. Find orders containing more than a specified number of items.

## 🚀 How to Run the Project

### Step 1: Clone the Repository

```bash
git clone <your-repository-url>
```

### Step 2: Open MySQL

Open **MySQL Workbench** or any MySQL client.

### Step 3: Run the SQL Script

Run the following file:

```text
sql/online_retail_analysis.sql
```

The script will:

* Create the `OnlineRetail` database.
* Create all required tables.
* Define foreign key relationships.
* Insert sample data.
* Execute SQL analysis queries.
